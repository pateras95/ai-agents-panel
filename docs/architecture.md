# Αρχιτεκτονική NEXUS AI

## Συσκευές και πρόσβαση

- **Ubuntu.** Εκεί τρέχουν IntelliJ, Codex και Claude Code και γίνεται η συλλογή από τα επιλεγμένα τοπικά projects. Η συνολική ροή δοκιμάζεται πρώτα εκεί.
- **Lenovo M10 FHD.** Φιλοξενεί το backend, το frontend build και τις εγκεκριμένες αναφορές. Η εκκίνηση και η εποπτεία γίνονται από το Ubuntu μέσω USB ADB.
- **Browser.** Διατηρούμε το υπάρχον dashboard σε Ubuntu και iPhone, με προαιρετική πρόσβαση από Windows. Η αρχική πρόσβαση περιορίζεται στο ίδιο Wi‑Fi. Το dashboard ανοίγει στο `http://192.168.1.238:18767/`. Η διεύθυνση δοκιμής `http://192.168.1.138:8766/` προωθεί εκεί.

## Δομή και κατάσταση

| Περιοχή | Σήμερα | Επόμενη υλοποίηση |
|---|---|---|
| `backend/` | HTTP server, ανάγνωση ορίων, τοπική συλλογή Git από εγκεκριμένα repos, προσχέδιο και ρητή έγκριση. | Επιλογή projects από το dashboard και τυχόν εγκεκριμένες εξωτερικές πηγές. |
| `frontend/` | Dashboard σε Vue 3 με Vuetify, πλοήγηση ανά προβολή, τέσσερα όρια, προσχέδιο και ιστορικό. | Επαλήθευση της ροής από επιπλέον συσκευές. |
| Αναφορές και δραστηριότητα | Το ενεργό ιστορικό αποθηκεύεται στο Lenovo, εκτός Git. Το Ubuntu διατηρεί το αρχικό αντίγραφο της μεταφοράς. | Τακτική δοκιμή ανάκτησης από αντίγραφο. |

## Δομή frontend

Το UI υλοποιείται με Vue 3, Vuetify, JavaScript και Composition API. Τα Vue components χρησιμοποιούν `<script setup>`. Μέσα στο `frontend/src/`, τα components για τα όρια χρήσης και τα stand-up μπαίνουν στο `components/`, η κοινή λογική ανάγνωσης στο `composables/` και η διαμόρφωση του θέματος Vuetify στο `plugins/`. Η εφαρμογή διατηρεί τη διεύθυνση δοκιμής και την προβολή για μικρές οθόνες.

## Ροή stand-up

1. Η τρέχουσα εγκατάσταση ορίζει τα εγκεκριμένα projects στον συλλέκτη. Στο Ubuntu ο συλλέκτης διαβάζει τις αντίστοιχες τοπικές τοποθεσίες και ομαδοποιεί τη δραστηριότητα ανά project και ημερολογιακή ημέρα σε `Europe/Athens`.
2. Η αυτόματη συλλογή χρησιμοποιεί commits που ταιριάζουν με την τοπική ταυτότητα author και τα διαθέσιμα branches. Για αλλαγές χωρίς commit, ο χρήστης μπορεί να συμπληρώσει το προσχέδιο χειροκίνητα. Τα τοπικά ίχνη push καταγράφονται ως ενδείξεις, με τυχόν ανεξάρτητη επιβεβαίωση από το Bitbucket να εμφανίζεται χωριστά.
3. Για Codex χρησιμοποιείται εγκεκριμένη πηγή με ελάχιστα στοιχεία δραστηριότητας ή σύντομη σύνοψη του χρήστη. Κάθε απόδοση εργασίας σε συγκεκριμένο εργαλείο χρειάζεται αντίστοιχο τεκμήριο.
4. Το προσχέδιο δίνει μία πρόταση ανά project με το αποτέλεσμα της δουλειάς. Η αναλυτική προεπισκόπηση περιέχει commits, branches, push, πηγές και εκκρεμότητες επιβεβαίωσης.
5. Ο χρήστης εγκρίνει το κείμενο. Μόνο τότε αποθηκεύεται ή αντικαθίσταται η μία εγκεκριμένη αναφορά της ημέρας. Στο dashboard οι εγκεκριμένες αναφορές εμφανίζονται με την πιο πρόσφατη πρώτη. Οι ενότητες «Επόμενα» και «Εμπόδια» εμφανίζονται μόνο όταν έχει επιβεβαιωθεί το κείμενό τους. Η χειροκίνητη καταχώριση παραμένει διαθέσιμη. Η διαγραφή μίας εγκεκριμένης αναφοράς απαιτεί επιβεβαίωση και έλεγχο ότι η εγγραφή παραμένει στην έκδοση που προβλήθηκε.

## Προγραμματισμένη συλλογή

Ο timer του Ubuntu εκτελεί τον συλλέκτη Δευτέρα έως Παρασκευή στις 18:00 ώρα Αθήνας. Αν το Ubuntu ήταν κλειστό, η συλλογή αναπληρώνει την πιο πρόσφατη ολοκληρωμένη εργάσιμη ημέρα. Τα προσχέδια αποθηκεύονται εκτός Git στο Ubuntu και το Lenovo τα ζητά μέσω USB. Το dashboard εμφανίζει τις ημερομηνίες που εκκρεμούν, με την αποθήκευση της τελικής αναφοράς να παραμένει ρητή ενέργεια του χρήστη.

## Όρια χρήσης

Το dashboard έχει τέσσερις μετρήσεις, 5ωρο και 7ήμερο για Claude Code και Codex. Για κάθε μέτρηση δείχνει ποσοστό που απομένει, ώρα επαναφοράς στην Αθήνα και, όταν είναι γνωστή, ώρα τελευταίας επιτυχούς ενημέρωσης της τιμής. Κάθε πεδίο χωρίς τιμή εμφανίζεται ως «Μη διαθέσιμο».

Η πηγή Claude Code είναι τα πεδία του status line, όπου επιτρέπεται η πρόσβαση βάσει πολιτικής MPASS. Η πηγή Codex είναι το App Server με αντιστοίχιση βάσει της διάρκειας του παραθύρου. Η συσχέτιση με το IntelliJ εκκρεμεί μέχρι να επιβεβαιωθούν ο ίδιος λογαριασμός και workspace.

## Διαδρομή συλλογής Ubuntu και Lenovo

Ο συλλέκτης ακούει στο Ubuntu στο `127.0.0.1:18769`. Ο επόπτης ανοίγει USB reverse tunnel στη θύρα `18769` πριν ξεκινήσει το backend στο Lenovo. Έτσι το Lenovo ζητά όρια και προσχέδια από το Ubuntu μέσω USB και σερβίρει το dashboard μέσω Wi-Fi στη θύρα `18767`. Τα αποθετήρια Git και οι συνδέσεις των CLI παραμένουν στο Ubuntu.

## Αποθήκευση και υπηρεσίες

Το ιδιωτικό GitHub repo περιέχει κώδικα και τεκμηρίωση του NEXUS AI. Τα εταιρικά repos βρίσκονται στο Bitbucket. Οι αναφορές και τα δεδομένα δραστηριότητας αποθηκεύονται μόνο τοπικά, εκτός Git. Αποθηκεύονται οι ελάχιστες πληροφορίες που χρειάζονται για τη σύνοψη, σύμφωνα με την πολιτική του οργανισμού. Πηγαίος κώδικας εταιρικών projects, πλήρη diffs, συνομιλίες, raw logs και credentials εξαιρούνται από τη συλλογή και την αποθήκευση δραστηριότητας.
